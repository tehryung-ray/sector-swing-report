# 파라미터 근거 (research)

프로덕션 파라미터를 왜 그 값으로 정했는지의 재현 가능한 증거.
**매매 파라미터를 근거 없이 바꾸지 않기 위한 기록이다.** 값을 고치려면 여기부터 다시 돌린다.

## 실행 순서

```bash
python research/fetch_all.py    # 시세 수집 -> research/all.pkl (git 미추적)
python research/verify.py       # 고속 엔진이 프로덕션과 같은 판단을 내리는지 검증
python research/wfo.py          # 워크포워드 최적화
python research/holdout.py      # 완전 격리 검증
python research/robust.py       # 안정 파라미터만 채택했을 때의 성과
python research/null2.py        # 귀무모형 - 신호가 무작위보다 나은가
```

## 결론 (2026-09-08, 22종목 38,690행)

### 1. 신호는 실재한다
지정가주문·손절·익절 장치를 전부 동일하게 두고 **진입일 선택만 무작위화**하면 -0.156%,
실제 신호는 +0.190%. 40회 시뮬레이션 전부를 상회(100 퍼센타일).

단, **단순 보유 대비 초과수익은 없다.** 같은 2.9일 보유 시 단순 보유 +0.235% vs 전략 +0.190%.
전략의 가치는 알파가 아니라 **시장 노출 시간 10.9%로 비슷한 수익을 낸다**는 데 있다.

### 2. 채택한 변경 (2개뿐)

| 파라미터 | 이전 | 이후 | 근거 |
|---|---|---|---|
| `gates.MIN_RR` | 1.2 | **1.5** | 워크포워드 6/6 폴드에서 선택, 훈련 상위 30개 중 18개 |
| `levels.TP1_ATR` | 1.5 | **2.0** | 훈련 상위 30개 중 **30개** 전부에서 선택 |

완전 격리 검증(2021~2026, 파라미터 선택에 한 번도 쓰이지 않음):

| | 거래 | 승률 | 거래당 평균 | t |
|---|---|---|---|---|
| 현행 | 1,129 | 46.6% | +0.212% | +1.98 |
| **로버스트 (위 2개만)** | 959 | 46.0% | **+0.366%** | **+2.91** |
| 훈련 최적 (6개 전부 튜닝) | 893 | 44.6% | +0.261% | +2.10 |

**6/6 연도에서 개선.**

### 3. 바꾸지 않은 것과 그 이유

`max_hold`, `extended_max`, `dip_atr`, `sh_max_loss` 는 **건드리지 않았다.**
폴드마다 다른 값이 뽑히거나(불안정), 최적화기가 현재값을 한 번도 고르지 않고
양극단만 오갔다(`dip_atr` 는 0.3/0.8 만 선택, 0.5 는 0회) — 노이즈를 학습한 징후다.

**과최적화가 실측으로 확인됐다.** 6개 파라미터를 전부 훈련 최적값으로 맞춘 조합은
검증구간에서 t=2.10 으로, 안정적인 2개만 바꾼 로버스트(t=2.91)보다 **나빴다.**

## 한계

- 2015~2019 구간은 종목이 5~8개뿐이고 일관되게 손실(-0.18~-0.46%)이다. 2020년부터 수익.
  체제 변화인지 유니버스 구성 효과인지 구분되지 않는다.
- MDD 는 매 거래에 전액을 투입하는 순차 가정이라 과장돼 있다.
  투입비중 25% 기준 MDD 는 20.7% 수준.
- 미국 섹터 필터를 `종가 > 20일선` 으로 단순화했다. 실제 파이프라인의 모멘텀 랭킹과 다르다.

# 레버리지 ETF 검증 (2026-09-08)

**결론: 도입하지 않는다.** 위험을 같게 맞추면 어떤 방식으로도 기초를 넘지 못했다.

```bash
python research/synth.py      # 합성 2배 시계열이 실물과 일치하는지 검증
python research/lev.py        # 실물 레버리지 ETF 7쌍
python research/lev_full.py   # 합성 레버리지, 전체 22종목
```

## 1. 통념 반박 — "레버리지는 녹는다"는 우리 전략엔 해당 없음

일일재조정 2배 상품의 변동성 끌림을 실측했다.

| 보유기간 | 끌림 |
|---|---|
| **5일** | **-0.09 ~ -0.27%p** |
| 20일 | -0.03 ~ -1.50%p |
| 60일 | -2.8 ~ -5.1%p |

우리 평균 보유는 3.1일이다. **이 구간에서 끌림은 사실상 없다.**
실현 배율도 정확히 2.0배(5일 기준 1.96~2.02, R² 0.97~0.99). 통념은 기각된다.

## 2. 진짜 문제 — % 기준값이 전부 절반 의미가 된다

2배 차트에 우리 규칙을 그대로 적용하면:

| 우리 기준 | 기초 기준 실제 의미 |
|---|---|
| 손절 -3% | **-1.5%** |
| 이격 상한 12% | **6%** |
| 눌림 구간 4% | **2%** |
| 최소 상승폭 1.5% | **0.75%** |

손절만의 문제가 아니다. 국면 분류 자체가 무너진다.
합성 검증에서 거래 수가 959 → 235건으로 급감했는데, 대부분이 과열로 오분류돼 걸러진 것이다.

## 3. 결과 (합성 2배, 22종목, 2021~2026)

| 변형 | 거래 | 승률 | 평균 | t | MDD | **½수량 수익/위험** |
|---|---|---|---|---|---|---|
| **기초** | 959 | 46.0% | +0.366% | **+2.91** | 64.6% | **0.094** |
| 레버 동일룰 | 235 | 30.2% | -0.097% | -0.20 | 89.3% | -0.013 |
| 레버 손절 2배 | 195 | 38.5% | +0.167% | +0.26 | 84.6% | 0.019 |
| 레버 전면재조정 | 277 | 41.9% | +0.400% | +0.72 | 93.2% | 0.043 |

재조정을 정교하게 할수록 기초에 가까워질 뿐, **한 번도 넘지 못한다**(0.094 vs 최선 0.043).
부트스트랩상 차이는 전부 "구분 불가"지만 **점추정이 셋 다 음수**(-0.41/-0.29/-0.17%p)로 방향이 일관된다.
MDD 는 모든 변형에서 크게 악화(64.6% → 84~93%).

실물 레버리지 ETF 7쌍(188거래)에서도 같은 패턴: 승률 41.0% → 33.1%.

## 4. 합성 시계열의 타당성

실물 레버리지 ETF 7종과 대조했다.

- 일간수익 상관 **0.984~0.995**, 5일수익 상관 0.996~0.999
- 다만 **합성이 실물보다 하루 +0.033%p 낙관적**이다(스왑비용·리밸런싱 슬리피지).
  운용보수 차이(0.0008%/일)보다 40배 크다. 이 실측 마찰을 차감해 보수적으로 계산했다.

## 5. 유동성

실물 레버리지 거래대금 / 기초 거래대금 (최근 60일):

| 종목 | 배수 |

방산 레버리지 13억은 스윙에 쓸 수 없다. 현재 게이트(5억)는 이걸 통과시킨다.

## 6. 요약

레버리지는 **수익률 개선 수단이 아니라 포지션 크기 조절 수단**이다.
2배를 절반 사면 기초 전량과 노출이 같고, 그 대가로 넓은 스프레드·낮은 유동성·
사전교육·기본예탁금·실측 마찰(-0.033%/일)을 치른다. 얻는 것은 자본 효율뿐이다.

**자본 제약이 없다면 도입할 이유가 없다.**

# 분할 개수 / 포지션 크기 (2026-09-08)

```bash
python research/portfolio.py
```

## 1. 산술 제약

`포지션 금액 = 거래당 위험금액 ÷ 손절률` 이므로
**동시보유 가능 종목 수 = 손절률 ÷ 위험비율** 로 고정된다.

| 거래당 위험 | 손절 -3% 기준 포지션 | 총자금 3,000만 기준 |
|---|---|---|
| 0.5% (15만) | 500만 | 6개까지 |
| 1.0% (30만) | 1,000만 | 3개까지 |
| 1.5% (45만) | 1,500만 | 2개까지 |

위험을 키우면 **분산이 불가능해진다.** 이게 1순위 제약이다.

## 2. 신호 공급 제약

슬롯 무제한 가정 시 동시보유 종목 수: **평균 3.4개, 중앙값 3개, 최대 14개**

| 동시보유 | 그만큼 채울 수 있는 시간 비중 |
|---|---|
| 3개 이상 | 58.3% |
| 4개 이상 | 41.3% |
| 5개 이상 | 27.5% |
| 6개 이상 | 17.3% |
| 8개 이상 | 6.3% |

**5개를 넘기면 슬롯이 대부분 비어 있다.**

## 3. 시뮬레이션 결과 (3,000만원, 2021~2026, 5.7년)

| 분할 | 위험 | 연환산 | MDD | 수익/MDD | 실제 평균보유 |
|---|---|---|---|---|---|
| 3 | 0.50% | +4.6% | 16.1% | 0.28 | 1.8개 |
| **4** | **0.50%** | **+6.2%** | **19.0%** | **0.33** | 2.1개 |
| **5** | **0.50%** | **+7.1%** | **21.0%** | **0.34** | 2.4개 |
| 6 | 0.50% | +7.1% | 22.5% | 0.32 | 2.4개 |
| 8 | 0.50% | +7.0% | 22.5% | 0.31 | 2.5개 |
| 5 | 0.75% | +7.5% | 26.5% | 0.28 | 2.1개 |
| 5 | 1.00% | +6.8% | 28.7% | 0.24 | 1.9개 |

**결론**
- **5개에서 포화.** 6·8로 늘려도 연환산이 그대로고 MDD만 커진다.
- **위험 0.5%가 최적.** 0.75%·1.0%로 올리면 수익은 거의 그대로인데 MDD가 21% → 26.5% → 28.7% 로 악화.
- 2분할은 명백히 부족(연 +2.3%, 슬롯 부족으로 480건을 놓침).
- 슬롯을 5개 줘도 **실제 평균 보유는 2.4개.** 현금이 절반 이상 남는 것이 정상이다.

## 한계

- MDD 는 실현손익 기준이라 평가손실은 반영되지 않았다. 실제 계좌 낙폭은 더 클 수 있다.
- 연 7% 수준이며, 백테스트 기간(2021~2026)의 한국 시장 환경에 의존한다.
- 포지션당 비중 상한을 34%로 두고 계산했다.

# 2차 익절: 고정 지정가 vs 트레일링 (2026-09-08)

```bash
python research/trail.py
```

**보류 중.** 방향은 맞으나 연도별 일관성이 과거 채택 기준(6/6)에 못 미친다.

## 몇 %가 맞나

검증구간 2021~2026, 2차 익절가 돌파 후 감시 시작, 감시 후 보유상한 20일.
현행(고정 지정가) 거래당 +0.510% 대비:

| 하락폭 | 현행 대비 | 하락폭 | 현행 대비 |
|---|---|---|---|
| 4% | −0.034%p | 8% | +0.133%p |
| 5% | −0.004%p | **9%** | **+0.180%p** |
| 6% | +0.033%p | 10% | +0.171%p |
| 7% | +0.077%p | 12% | +0.176%p |
| | | 15% | +0.157%p |

**5% 이하는 확실히 손해다.** 국내 섹터 ETF의 일간 ATR이 3~5%라 좁은 트레일링은
평범한 흔들림에 털린다. 8~15%가 넓은 고원을 이루고 9%가 최고점이다.
고원이 넓다는 것은 특정 값에 우연히 맞은 게 아니라는 뜻이라 그 자체로는 좋은 신호다.

ATR 배수 기준(ATR×3 등)도 시험했으나 고정 9%보다 못했고(+0.092%p) 실행도 복잡하다.

## 왜 채택하지 않았나

**1. 개선의 원인이 트레일링이 아니다.**
2차 익절을 아예 없애고 오래 들고만 있으면 더 낫다(20일 보유 +0.309%p).
즉 효과의 정체는 "고점 대비 하락 관리"가 아니라 "익절을 서두르지 않는 것"이다.
그런데 그 대가로 **MDD가 40% → 68%로 두 배**가 되고 승률이 46%→36%로 떨어진다.
위험을 더 진 것이지 개선이 아니다.

**2. 연도별 일관성이 4/6이다.**

| 연도 | 현행 | 트레일 9% | 차이 |
|---|---|---|---|
| 2021 | +0.077% | −0.061% | −0.138%p |
| 2022 | +0.044% | +0.066% | +0.022%p |
| 2023 | +0.703% | +0.870% | +0.167%p |
| 2024 | +0.230% | +0.201% | −0.029%p |
| 2025 | +0.782% | +1.288% | +0.506%p |
| 2026 | +0.633% | +0.884% | +0.251%p |

진 해는 작고 이긴 해는 크다. 훈련구간(2015~2020)에서도 7%/9%/12% 전부 개선이라
**방향은 뒤집히지 않는다.** 과열 게이트(구간마다 반대 방향)보다는 근거가 강하다.
다만 `min_rr`·`TP1_ATR`을 채택했던 6/6 기준에는 못 미친다.

## 쓰신다면

- **최소 7%, 권장 9%.** 3~5% 같은 값은 검증상 확실히 손해다.
- 감시가 걸린 종목은 **5거래일 상한에서 예외**로 둬야 효과가 난다.
  5일 상한을 유지하면 +0.180%p가 +0.077%p로 줄어든다.

## 부수 확인

**분할 청산이 1차 전량 청산보다 확실히 낫다.** 같은 구간에서 +0.510% vs +0.366%.
설명서가 안내하는 "1차에서 절반, 2차에서 나머지"가 초기 백테스트 모델보다 낫다.

# 파라미터 근거 (research)

프로덕션 파라미터를 왜 그 값으로 정했는지의 재현 가능한 증거.
**매매 파라미터를 근거 없이 바꾸지 않기 위한 기록이다.** 값을 고치려면 여기부터 다시 돌린다.

## 실행 순서

```bash
python research/fetch_all.py    # 시세 수집 -> research/all.pkl (git 미추적)
python research/verify.py       # 고속 엔진이 프로덕션과 같은 판단을 내리는지 검증
python research/wfo.py          # 워크포워드 최적화
python research/holdout.py      # 완전 격리 검증
python research/robust.py       # 안정 파라미터만 채택했을 때의 성과
python research/null2.py        # 귀무모형 - 신호가 무작위보다 나은가
```

## 결론 (2026-09-08, 22종목 38,690행)

### 1. 신호는 실재한다
지정가주문·손절·익절 장치를 전부 동일하게 두고 **진입일 선택만 무작위화**하면 -0.156%,
실제 신호는 +0.190%. 40회 시뮬레이션 전부를 상회(100 퍼센타일).

단, **단순 보유 대비 초과수익은 없다.** 같은 2.9일 보유 시 단순 보유 +0.235% vs 전략 +0.190%.
전략의 가치는 알파가 아니라 **시장 노출 시간 10.9%로 비슷한 수익을 낸다**는 데 있다.

### 2. 채택한 변경 (2개뿐)

| 파라미터 | 이전 | 이후 | 근거 |
|---|---|---|---|
| `gates.MIN_RR` | 1.2 | **1.5** | 워크포워드 6/6 폴드에서 선택, 훈련 상위 30개 중 18개 |
| `levels.TP1_ATR` | 1.5 | **2.0** | 훈련 상위 30개 중 **30개** 전부에서 선택 |

완전 격리 검증(2021~2026, 파라미터 선택에 한 번도 쓰이지 않음):

| | 거래 | 승률 | 거래당 평균 | t |
|---|---|---|---|---|
| 현행 | 1,129 | 46.6% | +0.212% | +1.98 |
| **로버스트 (위 2개만)** | 959 | 46.0% | **+0.366%** | **+2.91** |
| 훈련 최적 (6개 전부 튜닝) | 893 | 44.6% | +0.261% | +2.10 |

**6/6 연도에서 개선.**

### 3. 바꾸지 않은 것과 그 이유

`max_hold`, `extended_max`, `dip_atr`, `sh_max_loss` 는 **건드리지 않았다.**
폴드마다 다른 값이 뽑히거나(불안정), 최적화기가 현재값을 한 번도 고르지 않고
양극단만 오갔다(`dip_atr` 는 0.3/0.8 만 선택, 0.5 는 0회) — 노이즈를 학습한 징후다.

**과최적화가 실측으로 확인됐다.** 6개 파라미터를 전부 훈련 최적값으로 맞춘 조합은
검증구간에서 t=2.10 으로, 안정적인 2개만 바꾼 로버스트(t=2.91)보다 **나빴다.**

## 한계

- 2015~2019 구간은 종목이 5~8개뿐이고 일관되게 손실(-0.18~-0.46%)이다. 2020년부터 수익.
  체제 변화인지 유니버스 구성 효과인지 구분되지 않는다.
- MDD 는 매 거래에 전액을 투입하는 순차 가정이라 과장돼 있다.
  투입비중 25% 기준 MDD 는 20.7% 수준.
- 미국 섹터 필터를 `종가 > 20일선` 으로 단순화했다. 실제 파이프라인의 모멘텀 랭킹과 다르다.
